# Model Development Track

Initial language focus: **Amharic** and **Afaan Oromo**.

The final task is intentionally not fixed yet. Candidate model directions include:
- English ↔ Amharic/Afaan Oromo public-service translation
- quality estimation for high-consequence institutional translations
- institutional terminology preservation
- translation-risk/error detection
- multilingual public-benefit retrieval or question answering

Model development should begin only after:
1. sufficient validated data exists,
2. licensing permits training/release,
3. native-speaker review is in place,
4. baseline systems are documented,
5. a clearly bounded task is selected.

Any Hugging Face model release should include a Model Card, evaluation by language and domain, known failure modes, intended use, and explicit limits for high-stakes public-benefit decisions.
